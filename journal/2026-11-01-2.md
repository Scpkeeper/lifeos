# 2026-11-01 开发日志（二）

这一个版本实现了 Whisper 端侧模型，首次使用模型需要下载，然后接入了一个 Whisper 模型来实现那个语音转文字。

技术要点：
- 用开源 Whisper（端侧 / on-device）替换原先占位的语音识别流程。
- 通过 transformers.js（WASM）动态加载多语 `whisper-tiny` 模型，指定 `language:'zh'`，无需任何 API key，可离线运行。
- 首次使用需下载模型（约 75MB，经浏览器 Cache API 缓存，带下载进度条 `#voiceProg`）。
- 录音链路：`getUserMedia` → `MediaRecorder` → Blob → `OfflineAudioContext` 重采样为 16kHz 单声道 → Whisper pipeline 转写。
- 微信式长按手势：上滑 / 左滑发送（自动创建待办），右滑取消，松手无方向则填入文本框待确认。
- Android 清单新增 `RECORD_AUDIO` 权限。
- 暴露 `loadWhisper / transcribeViaWhisper / startRec / stopRec / recordThenTranscribe` 到 `window.LifeOS` 便于调试。

校验：
- NUL 哨兵字节未损（root / www 各 4/4）。
- smoke test 73/73 通过，0 运行时错误。
