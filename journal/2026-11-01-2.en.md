# 2026-11-01 Dev Log (2)

This version ships the on-device Whisper model. The model is downloaded on first use, and a Whisper model is integrated to power speech-to-text.

Technical notes:
- Replaced the previous placeholder speech-recognition flow with open-source Whisper (on-device).
- Loads the multilingual `whisper-tiny` model via transformers.js (WASM) with `language:'zh'`. No API key required; runs fully offline.
- First launch downloads the model (~75MB, cached via the browser Cache API, with a download progress bar `#voiceProg`).
- Capture chain: `getUserMedia` → `MediaRecorder` → Blob → `OfflineAudioContext` resampled to 16kHz mono → Whisper pipeline transcription.
- WeChat-style hold-to-talk gestures: swipe up / left to send (auto-creates a todo), swipe right to cancel, release without direction fills the input box pending confirmation.
- Added the `RECORD_AUDIO` permission to the Android manifest.
- Exposed `loadWhisper / transcribeViaWhisper / startRec / stopRec / recordThenTranscribe` on `window.LifeOS` for debugging.

Verification:
- NUL sentinel bytes intact (4/4 in both root and www).
- Smoke test 73/73 passed, 0 runtime errors.
