# 2026-11-03 开发日志

- 用一部红米手机（MIUI）通过 USB 调试连到电脑，借助 Android Studio 自带的 adb 把 APK 推到 /sdcard/Download 本地安装（MIUI 会拦截 adb install）。
- 通过 adb logcat 抓取原生崩溃栈，定位到两个 bug：①开启通知时闪退 —— @capacitor/local-notifications 的 cancel() 要求 notifications 里每个元素是 {id:数字} 对象，而我传了纯数字数组，导致原生层 ClassCastException 硬崩；②打开应用闪退 —— 启动期过早调用原生通知接口，桥接未就绪所致。
- 修复：cancel 改为 ids.map(n=>({id:n})) 且空数组不调用；移除启动期原生调用并加 notifReady 手势门控。三套 jsdom 测试全绿（78/78 + 8/8 + 13/13）。
