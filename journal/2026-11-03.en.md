# 2026-11-03 Dev Log

- Connected a Redmi phone (MIUI) to the PC via USB debugging and used the `adb` bundled with Android Studio to push the APK into /sdcard/Download for local install (MIUI blocks `adb install`).
- Captured the native crash stack via `adb logcat` and pinned down two bugs: (1) crash when enabling notifications — `@capacitor/local-notifications`' `cancel()` requires each element in `notifications` to be a `{id:number}` object, but we passed a plain number array, causing a native `ClassCastException` hard crash; (2) crash on app launch — native notification APIs were called too early at startup before the Capacitor bridge was ready.
- Fix: `cancel` now maps ids to `{id:n}` objects and is skipped when empty; removed startup native calls and added a `notifReady` gesture gate. All three jsdom suites green (78/78 + 8/8 + 13/13).
